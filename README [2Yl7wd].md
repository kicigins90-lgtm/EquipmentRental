# Задача 1. Банковский счёт (25 минут)

**Ситуация:** банк предоставляет клиентам счета, которые можно пополнять и с которых можно снимать деньги.

Нужно разработать класс `BankAccount`:

- Поля owner и balance должны быть закрытыми.
- Конструктор задаёт владельца и начальный баланс.
- Метод `deposit(double amount)` пополняет счёт.
- Метод `withdraw(double amount)` снимает деньги.
- Сумма операции должна быть строго больше нуля; нельзя снять больше доступного остатка.
- Метод `showInfo()` показывает владельца и остаток.
В main создать два счёта и показать успешные и ошибочные операции.


# Задача 2. RPG-персонажи (35 минут)
**Ситуация:** персонажи участвуют в пошаговом сражении.

Создайте базовый класс `GameCharacter` с полями name, `health`, `attackPower`, конструктором и методами:

- attack(GameCharacter target) — атаковать указанного персонажа;
- takeDamage(int damage) — получить урон, не опуская здоровье ниже 0;
- isAlive() — проверить, жив ли персонаж;
- showStatus() — вывести состояние.
Далее:

- Создайте `Warrior extends GameCharacter` с увеличенным стартовым здоровьем.
- Создайте `Mage extends GameCharacter`, переопределяющий `attack()` (усиленный урон).
- Проведите обмен атаками.
- Создайте массив `GameCharacter[]` из разных персонажей и вызовите их общий метод `showStatus()`.
